## 41. polymorphism

How many Homo sapiens physical entities share a non-empty name, taken from the name slot and matched exactly and case-sensitively, with a reference entity other than their own reference entity? An entity with no reference entity counts if it shares a name with any reference entity.

**Expected** — baseline (int):

```json
2090
```

**Stores that disagree:**

- `neo4j`: 2089
- `typedb`: 2089

> The relational dump holds a ReferenceGeneProduct the graph does not: 9663770 (UniProt:Q9JKQ2 SLC26A5), whose name SLC26A5 is also a name of the human entity 5216108 (SLC26A5 [plasma membrane]), which points at a different reference gene product (62142). Confirmed by diffing the answer sets: that entity is the single one MySQL reports and Neo4j does not. TypeDB is loaded from the graph, so it matches Neo4j. The question says non-empty because 65 Reactome name lists carry a trailing empty string (e.g. RHOG's ["RHOG", "RhoG", ""]); the TypeDB export drops it as a data-entry artefact, so without the exclusion Neo4j and MySQL match 22 more entities to reference entities through the empty string (2111 and 2112) while TypeDB reports 2089. MySQL's default collation compares strings case-insensitively; joining the two name tables without BINARY returns 5217, because human names such as INS then match names such as Ins on reference entities of other species.

**cypher**

```cypher
CALL {
    MATCH (p:PhysicalEntity)-[:species]->(:Species {displayName:'Homo sapiens'})
    UNWIND p.name AS n
    RETURN n, p AS x, 'pe' AS k
    UNION ALL
    MATCH (r:ReferenceEntity)
    UNWIND r.name AS n
    RETURN n, r AS x, 're' AS k }
WITH n, collect(CASE WHEN k = 'pe' THEN x END) AS ps, collect(CASE WHEN k = 're' THEN x END) AS rs
WHERE n <> ''
AND size(ps) > 0
AND size(rs) > 0
UNWIND ps AS p
UNWIND rs AS r
WITH DISTINCT p, r
WHERE NOT (p)-[:referenceEntity]->(r)
RETURN count(DISTINCT p)
```

**sql**

```sql
WITH pesp AS (
    SELECT DB_ID, species
    FROM GenomeEncodedEntity
    WHERE species IS NOT NULL
    UNION ALL
    SELECT DB_ID, species
    FROM SimpleEntity
    WHERE species IS NOT NULL
    UNION ALL
    SELECT DB_ID, species
    FROM Cell_2_species
    UNION ALL
    SELECT DB_ID, species
    FROM Complex_2_species
    UNION ALL
    SELECT DB_ID, species
    FROM EntitySet_2_species
    UNION ALL
    SELECT DB_ID, species
    FROM Polymer_2_species),
hs AS (
    SELECT DISTINCT pesp.DB_ID
    FROM pesp
    JOIN DatabaseObject s ON s.DB_ID = pesp.species
    AND s._displayName = 'Homo sapiens'),
refs AS (
    SELECT DB_ID, referenceEntity
    FROM EntityWithAccessionedSequence
    WHERE referenceEntity IS NOT NULL
    UNION ALL
    SELECT DB_ID, referenceEntity
    FROM SimpleEntity
    WHERE referenceEntity IS NOT NULL
    UNION ALL
    SELECT DB_ID, referenceEntity
    FROM Drug
    WHERE referenceEntity IS NOT NULL)
SELECT COUNT(DISTINCT hs.DB_ID)
FROM hs
JOIN PhysicalEntity_2_name pn ON pn.DB_ID = hs.DB_ID
JOIN ReferenceEntity_2_name rn ON BINARY rn.name = BINARY pn.name
WHERE pn.name <> ''
AND NOT EXISTS (
    SELECT 1
    FROM refs
    WHERE refs.DB_ID = hs.DB_ID
    AND refs.referenceEntity = rn.DB_ID);
```

**typeql**

```typeql

    $p isa physical-entity, has entity-name $n;

    };
```
